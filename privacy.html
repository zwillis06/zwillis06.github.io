Privacy policy

Effective 15 October 2026.

Purpose and operator

The Future Files is a personal automation operated by the owner of the connected YouTube channel. It prepares, archives, uploads, schedules, and verifies videos for that owner's account. This website provides information and does not collect account credentials.

Google data accessed

The automation receives OAuth authorization tokens. Its Drive permission is limited to app-created or user-selected files. It reads and writes generated video files, story scripts, production journals, and story history in the authorized archive. YouTube permissions allow uploads and read-only access used to verify channel identity, video processing, publication schedules, and visibility.

How data is used and shared

Google data is used only to perform the described channel automation. Google processes Drive storage and YouTube publication. GitHub Actions processes production files and uses credentials stored in encrypted repository secrets. The owner's local computer holds private authorization files used during setup. Scripts are generated with the Gemini API using public source material and prior generated story titles; OAuth credentials are not included in generation prompts. The operator does not sell Google data or use it for advertising.

Storage and retention

Generated videos and production records remain in the owner's Drive archive until the owner removes them. GitHub run artifacts are configured to expire after seven days. GitHub workflow logs follow the repository's retention settings. Local setup credentials remain on the owner's computer until removed. Access is limited by the owner's Google and GitHub account permissions.

Revocation and deletion

The owner can revoke the app through Google Account connections, remove Actions secrets, disable the workflow, and delete generated Drive files, YouTube videos, GitHub artifacts, or local authorization files. Revocation stops future authorized requests; it does not automatically delete videos already published.

Limited use

The Future Files' use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements. Google user data is not used to train generalized AI models by this automation.

Website and contact

This static information website has no application login, advertising, or analytics code. Its hosting provider may process standard request information to serve the site. Questions about this tool can be directed to its owner through the connected YouTube channel.

This policy describes the current personal automation. Material changes to its data use should be reflected here before they take effect.
